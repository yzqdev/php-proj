# 代码评审

对当前改动或指定范围执行 PHP 代码评审。

## 范围

- 默认审查 `git status`、`git diff`、`git diff --cached` 中的改动。
- 用户指定分支、commit 或文件时按指定范围。
- 只读分析，不修改代码，除非用户明确要求修复。

## 检查项

1. **正确性**：逻辑分支、边界条件、空值、异常路径、并发。
2. **版本兼容**：语法与 API 是否符合项目 `require.php`；见 `.agents/docs/php-version-matrix.md`。
3. **安全**：按 `.agents/skills/security/SKILL.md` 检查注入、XSS、CSRF、SSRF、上传、路径、认证授权、密钥。
4. **数据访问**：参数化查询、事务边界、N+1、索引、连接管理。
5. **错误处理与日志**：异常是否被吞、是否记录上下文、是否泄漏敏感信息。
6. **API 契约**：状态码、响应结构、分页、校验、错误格式。
7. **质量**：命名、分层、重复代码、可测试性、静态分析问题。
8. **测试**：是否覆盖关键路径与失败路径。
9. **性能**：明显热点、无界循环、大对象、阻塞调用。

## 输出

按严重程度分组：

```text
[阻断] 必须修复，否则不能合并
[重要] 应修复，影响正确性/安全/性能
[建议] 可优化，不阻断
```

每条包含：文件与行号、问题、原因、修复建议。不要只给结论，要能定位。

## 完成后

- 更新 `.agents/memory/worklog.md`。
- 若发现新坑，记录到 `.agents/memory/known-issues.md`。
