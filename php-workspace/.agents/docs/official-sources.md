## 八、资料使用方式

1. **先官方，后社区**：API 签名、配置项、版本行为只信官方文档。
2. **看对应版本**：Laravel/Symfony/PHPUnit 文档都按版本发布，确认 URL 中的版本段。
3. **Packagist 看约束**：安装前看包的 `require` 与最近发布记录。
4. **GitHub README 补充**：官方文档缺失时，优先看仓库 README、示例目录、CHANGELOG。
5. **不复制整篇文档**：工作区只保留结论、用法与示例，详细内容链接到官方。
6. **引用标注**：在工作区文档中写结论时给出官方链接，便于后续核对。
